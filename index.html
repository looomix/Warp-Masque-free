HOW
工作原理

        

          
01
Actions 注册设备
工作流在 GitHub Runner 中运行 usque 完成 WARP/MASQUE 设备注册，密钥只在 Runner 与产物中短暂存在。

          
02
脚本生成订阅
scripts/generate.py 把账号转换为 Mihomo 兼容的 MASQUE YAML，并做结构与字段校验。

          
03

可选择把 YAML 提交到仓库，由 GitHub Pages 与 gh-proxy 镜像提供订阅；页面本地只做读取和预览。

        

      


      

        
FAQ
常见问题

        

          
为什么用 GitHub Actions？
Cloudflare 注册接口不允许浏览器跨域调用，而 GitHub Actions 的 Runner 是服务端环境，可以直接运行 usque 完成注册。生成的 YAML 提交回仓库后，GitHub Pages 就能作为公开订阅源，不需要 Cloudflare Worker。

          
AWG 档位会改变 WARP 服务端吗？
不会。Cloudflare 始终是标准 WireGuard peer；AWG 1.5/2.0/3.x 参数只写在客户端配置的 Interface 段，用于握手伪装与填充。

          
订阅链接格式？
Actions 生成的订阅地址是 https://looomix.github.io/Warp-Masque-free/configs/warp-masque.yaml，可直接填入 Clash / Mihomo（需要 Alpha 内核支持 masque）。每次重新运行工作流都会替换成全新账号。

          
合规说明
非官方项目，与 Cloudflare、Amnezia 无关联。使用 WARP 请遵守 Cloudflare 条款与所在地区法律。
