HOW
工作原理

        

          
01
本地生成密钥
浏览器用 Web Crypto 生成 X25519（WireGuard）与 P-256（MASQUE）密钥对，私钥不会离开设备。

          
02
Worker 注册设备
你部署的 Cloudflare Worker 转发注册请求到 Cloudflare API，并把 AES/设备令牌返回给页面。

          
03
多格式输出
本地组装 AWG/WireGuard .conf、MASQUE Clash YAML，并用 Worker 生成可直接导入的订阅地址。

        

      


      

        
FAQ
常见问题

        

          
为什么一定要部署 Worker？
Cloudflare 注册接口不允许浏览器跨域调用，m2c 等站点也依赖自己的服务端。Worker 免费且只需部署一次，仓库内已包含完整代码与部署按钮。

          
AWG 档位会改变 WARP 服务端吗？
不会。Cloudflare 始终是标准 WireGuard peer；AWG 1.5/2.0/3.x 参数只写在客户端配置的 Interface 段，用于握手伪装与填充。

          
订阅链接格式？
配置 Worker 后，订阅地址为 https://你的Worker/sub/<token>，可直接填入 Clash/Mihomo。无 Worker 时退化为本地 #sub= 链接，打开本页可恢复配置。

          
合规说明
非官方项目，与 Cloudflare、Amnezia、m2c 作者无关联。使用 WARP 请遵守 Cloudflare 条款与所在地区法律。
