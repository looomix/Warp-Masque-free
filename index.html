FAQ
常见问题

        

          
为什么一键注册可能失败？
原注册服务只允许授权域名（如 masque.pages.dev）来源访问，GitHub Pages 域名不在白名单。此时请到原站获取账号 JSON 后粘贴到本页，或在“注册接口”中填入你自己的兼容 Worker。

          
订阅链接能直接在 Clash 里用吗？
本地订阅链接需要在本页打开后才能解码出 YAML。若要在 Clash 中作为远程订阅使用，请填写一个实现了 /api/sub 的订阅托管 API，页面会上传 YAML 并返回真实订阅地址。

          
私钥会上传吗？
转换过程完全在本地进行。只有当你主动填写订阅托管 API 时，YAML 才会被发送到该地址；本地订阅链接本身包含私钥，请谨慎分享。

          
与原站的关系？
本页参考 m2c.pages.dev 的选项与配置结构独立实现，与其作者无关联。
