HOW IT WORKS
配置是怎么组装的
完全复刻 awgconfig.com 的配置结构，但计算过程放在浏览器里。

        

          
01
Interface 段
写入私钥、地址、DNS 与 MTU。AWG 1.5 使用静态混淆字段；2.0 起加入随机 Jc / Jmin / Jmax 与 S1–S4、H1–H4。

          
02
CPS / I1 伪装
握手前生成一段 SIP / QUIC / DNS 风格的十六进制载荷，以 <b 0x…> 形式写入 I1，让流量起点不像 WireGuard。

          
03
AWG 3.x 时序参数
加入 ContentPaddingAddition、RekeyAfterTime、RekeyTimeout、RejectAfterTime、KeepaliveTimeout、MaxHandshakeAttempts 等客户端侧随机区间。

FAQ
常见问题

        

          
为什么不能像原站一样一键注册 WARP？
原站有服务端负责向 Cloudflare 注册设备。GitHub Pages 只能托管静态文件，浏览器直接调用 Cloudflare API 会被 CORS 拦截。因此本站要求你导入已经注册的 WARP 密钥，或使用自建服务器密钥。注册步骤可用官方客户端或 wgcf 完成。

          
密钥会被上传吗？
不会。页面没有任何后端请求；所有生成逻辑都在浏览器内执行。历史记录也只写入你自己的 localStorage，可随时清空。

          
分流路由准确吗？
内置的是一组示例 CIDR，便于演示分流写法，并非实时更新的完整域名 IP 库。生产使用请替换为官方或自己维护的网段列表，并注意不要把 Endpoint IP 放进隧道路由。

          
为什么 vpn:// 不可用？
AmneziaVPN 的 vpn:// 是二进制 protobuf 经 base64url 编码后的链接，需要专门的编码器。本站优先提供通用性更好的 .conf 文件。

          
与 awgconfig.com 是什么关系？
本站是受其启发、参照其公开配置结构实现的静态演示版本。原项目由 HereIamGosu 开源，协议为 AGPL-3.0；本仓库保留 LICENSE 与出处说明。
